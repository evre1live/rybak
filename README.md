# Рыбак

Рыбалка с друзьями от первого лица: зашли в бухту, включили голос — болтаем и ловим.
Улов продаётся на рынке, на выручку покупаются удочки, леска, катушки, наживка и приманки.
Каждый играет за одного из девяти героев — у каждого своё телосложение, возраст, характер и свои цвета.
У пирса дают напрокат лодку с мотором: на ней выходят в открытое море, к затонувшему кораблю,
на Пальмовый остров и к причалу у маяка — и ловят прямо с борта.

## Запуск

```bash
npm install
npm start          # http://localhost:3000
```

Клиент уже собран (`public/app.js`). После правок в `client/` или `shared/` пересоберите: `npm run build`
(или `npm run dev` — пересборка при каждом сохранении).

Выкладка на Render: New → Blueprint → этот репозиторий. Настройки лежат в `render.yaml`.

Пробная версия одним файлом, без сервера (только одиночная рыбалка): `npm run solo` → `dist/rybak-solo.html`.

## Как устроено

- `shared/data.js` — рыба, снасти, зоны бухты, часы; `shared/logic.js` — клёв, выбор рыбы, вываживание, цены, рынок, профиль.
- `server/` — Node + ws: комнаты по коду из 4 символов, рассылка положений 12 раз в секунду, события, чат, голос.
  Рыбалка считается в браузере игрока; сервер держит общие часы бухты и зерно комнаты (по нему у всех одинаковые
  цены на рынке и косяки рыбы).
- `client/` — three.js без движка. Мир, вода, удочки и рыба строятся кодом — это запасной вид: он виден,
  пока грузятся готовые модели (и в пробной версии одним файлом), а потом модели встают на те же места.
  - `terrain.js`, `world.js`, `scenery.js`, `water.js` — бухта, свет по времени суток (в `water.js` — и прибой: кромка
    воды «дышит», к берегу идут пенные валы, песок у воды мокрый); `places.js` — острова и причалы за бухтой;
  - `surface.js` — фактура всего, что собрано кодом: земля (трава, камень, песок, тропа — рисованные текстуры из
    `public/tex/`, границы между ними ведёт шум), скалы и валуны (та же каменная кладка с трёх сторон, мох сверху),
    дерево, крашеные доски, черепица; `grass.js` — пучки травы и цветы вокруг игрока;
  - `gfx.js` — отрисовка и своя тональная кривая (тени не проваливаются в чёрное, цвет не уходит в рыжий).
    На «высоком» качестве: свечение, отражение мира в воде (сцена глазами зеркальной камеры — в буфер половинного
    размера, через кадр) и мягкая тень в углах по буферу глубины. Для проверок: `?refl=0` — без отражений,
    `?ao=0…1[,радиус,сила]` — затенение; на ходу — `RYBAK.gfx.reflect` и `RYBAK.gfx.aoK`;
  - `hero.js`, `models.js` — готовые модели героев, рыбы и предметов; `envmodels.js`, `scatter.js` — модели локации:
    лес и камни сотнями копий (рядом — подробные и с тенью, вдали — грубые), маяк, домик смотрителя (ночью в нём
    горят окна), корабль, хижина, будка проката, фонари, скамейки, указатель, чайки, костёр;
  - `boat.js` — лодка напрокат: ход, качка, след за кормой, лодки друзей;
  - `character.js` — персонаж: игрок выбирает героя, других персонажей нет. Кукла из частей, с которой игра начиналась,
    осталась невидимым «скелетом»: по ней считаются позы, герой их повторяет. Пока модель героя грузится, персонажа
    не видно; саму куклу видно только там, где моделей нет вовсе (пробная версия одним файлом);
  - `viewmodel.js`, `fparms.js` — удочка и руки героя от первого лица (у них свой угол обзора, от настроек не зависит);
  - `gear3d.js`, `fish3d.js`, `icons.js` — снасти, рыба, значки и портреты;
  - `player.js`, `fishing.js` — управление и сама рыбалка; `remote.js` — друзья;
  - `net.js`, `voice.js` — связь и голосовой чат (WebRTC, при строгой сети — через сервер);
  - `ui.js` + `public/style.css` — интерфейс; `audio.js` — звук, синтезируется в браузере.
- Прогресс хранится в браузере игрока (`localStorage`).

## Модели

Сырые модели делает Tripo по описаниям из `art/models.json`: `node tools/tripo.js` (ключ — в `.env`, расход кредитов —
в `art/tripo/state.json`, сырые файлы в репозиторий не попадают). `node tools/optimize.js [id]` приводит их к виду игры:
наибольший размер 1, стоит на земле; сетка упрощена, текстуры в WebP, геометрия сжата; моделям локации делается дальняя
копия без текстуры (`<id>.lod.glb`). Результат и список (`manifest.json`) лежат в `public/models/`.
Где у модели сиденье, вывеска или комель, меряют скрипты из `tools/dev/` — по этим замерам модели и расставлены.
Окнам, которые ночью светятся, в `art/models.json` задают `glow` — коробки со стёклами (их находит
`tools/dev/windows.mjs`): `optimize.js` рисует по ним карту свечения, днём она погашена.

Текстуры земли и камня (`public/tex/*.webp`) рисует `node tools/paint-textures.js [папка для просмотра]`: мазки травы,
каменная кладка, песок, тропа — бесшовные, в игре умножаются на цвет вершин.

Герой — модель со скелетом и тремя анимациями (стойка, шаг, бег): `tripo.js concept → model → rig → anim`, затем
`optimize.js`. В `art/models.json` у героя: `about` — строка на экране «Персонаж», `tall` — рост относительно обычного
(1,76 м вместе с шапкой), `eye` — высота глаз от первого лица, `fp` — цвета запасных рук и `fp.k` — размер рук героя
в кадре. Эти сведения без пересборки моделей обновляет `node tools/optimize.js --meta`. Портреты запекает
`node tools/bake-icons.cjs --faces` (игра должна быть запущена локально).

## Проверки

```bash
npm test                        # правила, сервер, причалы и зоны моря
npm start & npm run test:play   # одиночная игра в настоящем браузере, все экраны
npm run test:coop               # двое в одной комнате: лобби, голос, улов друга, обрыв связи
npm run test:devices            # телефон (управление пальцами), страница без захвата мыши, пробная версия без сервера
npm run balance                 # заработок в минуту и исход поединков по наборам снастей
```

Для автопроверок у страницы есть параметры: `?q=low|medium|high` — качество, `?h=13` — час суток,
`?ts=3` — ускорение времени, `?norender` — без отрисовки.

Свой TURN для голоса можно подключить переменными окружения `TURN_URLS`, `TURN_USERNAME` + `TURN_CREDENTIAL`
или `TURN_SECRET`.
