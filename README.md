# Рыбак

Рыбалка с друзьями от первого лица: зашли в бухту, включили голос — болтаем и ловим.
Улов продаётся на рынке, на выручку покупаются удочки, леска, катушки, наживка и приманки.
У каждого свой персонаж: телосложение, лицо, причёска, борода, головной убор, одежда и цвета.
У пирса дают напрокат лодку с мотором: на ней выходят в открытое море, к затонувшему кораблю,
на Пальмовый остров и к причалу у маяка — и ловят прямо с борта.

## Запуск

```bash
npm install
npm start          # http://localhost:3000
```

Клиент уже собран (`public/app.js`). После правок в `client/` или `shared/` пересоберите: `npm run build`
(или `npm run dev` — пересборка при каждом сохранении).

Выкладка на Render: New → Blueprint → этот репозиторий. Настройки лежат в `render.yaml`.

Пробная версия одним файлом, без сервера (только одиночная рыбалка): `npm run solo` → `dist/rybak-solo.html`.

## Как устроено

- `shared/data.js` — рыба, снасти, зоны бухты, часы; `shared/logic.js` — клёв, выбор рыбы, вываживание, цены, рынок, профиль.
- `server/` — Node + ws: комнаты по коду из 4 символов, рассылка положений 12 раз в секунду, события, чат, голос.
  Рыбалка считается в браузере игрока; сервер держит общие часы бухты и зерно комнаты (по нему у всех одинаковые
  цены на рынке и косяки рыбы).
- `client/` — three.js без движков и готовых моделей: мир, вода, персонажи, удочки и рыба строятся кодом.
  - `terrain.js`, `world.js`, `scenery.js`, `water.js` — бухта, свет по времени суток; `places.js` — острова и причалы за бухтой;
  - `boat.js` — лодка напрокат: ход, качка, след за кормой, лодки друзей;
  - `character.js`, `viewmodel.js`, `gear3d.js`, `fish3d.js`, `icons.js` — персонажи, руки от первого лица, снасти, рыба, иконки;
  - `player.js`, `fishing.js` — управление и сама рыбалка; `remote.js` — друзья;
  - `net.js`, `voice.js` — связь и голосовой чат (WebRTC, при строгой сети — через сервер);
  - `ui.js` + `public/style.css` — интерфейс; `audio.js` — звук, синтезируется в браузере.
- Прогресс хранится в браузере игрока (`localStorage`).

## Проверки

```bash
npm test                        # правила, сервер, причалы и зоны моря
npm start & npm run test:play   # одиночная игра в настоящем браузере, все экраны
npm run test:coop               # двое в одной комнате: лобби, голос, улов друга, обрыв связи
npm run test:devices            # телефон (управление пальцами), страница без захвата мыши, пробная версия без сервера
npm run balance                 # заработок в минуту и исход поединков по наборам снастей
```

Для автопроверок у страницы есть параметры: `?q=low|medium|high` — качество, `?h=13` — час суток,
`?ts=3` — ускорение времени, `?norender` — без отрисовки.

Свой TURN для голоса можно подключить переменными окружения `TURN_URLS`, `TURN_USERNAME` + `TURN_CREDENTIAL`
или `TURN_SECRET`.
